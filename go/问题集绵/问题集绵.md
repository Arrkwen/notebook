## 关于compile: version "go" does not match go tool version "go" 类问题解决

### 1.删除

 /usr/bin/ 下面的所有与go 相关的文件，先查看/usr/local/go/bin/*有哪些文件，再对应的删除

`sudo rm go*`

### 2.删除低版本的 go

`sudo rm -rf /usr/local/go`

### 3.下载

下载新的go 并且解压到 /usr/local/, 下载地址，[官网](https://go.dev/dl/)，[国内镜像网](https://golang.google.cn/dl/)

`sudo tar -xzf go1.xx.linux-amd64.tar.gz -C /usr/local`

### 4.建立软链

`sudo ln -s /usr/local/go/bin/* /usr/bin/`
[原文链接](https://blog.csdn.net/qq_40020447/article/details/104113490)


## 命令没有sudo权限

因为用户path和全局path是不一样，即环境变量不一致，所以有的命令没有sudo，只需要将命令写到/usr/bin下，就可以了

比如

`sudo ln -s command_path/bin/command  /usr/bin`
