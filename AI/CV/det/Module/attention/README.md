# 注意力模块

注意力模块对特征进行**通道维**或**空间维**的重标定，突出重要通道或空间位置，抑制次要信息，常用于 Backbone/Neck 中提升表达。这里实现**通道注意力 SE** 与**空间注意力 SAM**。

---

## 1. SE（Squeeze-and-Excitation）

**出处：** Squeeze-and-Excitation Networks (CVPR 2018)

**思想：** **通道注意力**：先对每个通道做全局池化（Squeeze）得到通道描述，再经两层全连接 + 激活（Excitation）得到每个通道的权重，最后与原特征逐通道相乘，实现“重标定通道重要性”。

**公式：**

- Squeeze：\( s_c = \text{GAP}(x_c) \)，即每个通道一个标量。
- Excitation：\( e = \sigma(W_2 \cdot \text{ReLU}(W_1 s)) \)，\( W_1 \) 将 C 维压到 C/r，\( W_2 \) 再扩回 C。
- 输出：\( \tilde{x}_c = e_c \cdot x_c \)。

**结构示意：**

```
输入 (C,H,W) ──→ [GlobalAvgPool] ──→ (C,) ──→ [FC → C/r] ──→ ReLU ──→ [FC → C] ──→ Sigmoid ──→ 权重 (C,1,1)
      │                                                                                    ↓
      └────────────────────────────────────────────── 逐通道乘 ──────────────────────────────→ 输出
```

- **reduction ratio r**：中间层通道为 C/r，用于控制参数量与表达能力。

---

## 2. SAM（Spatial Attention Module）

**思想：** **空间注意力**：对通道维做聚合（如沿通道取最大/平均）得到 2D 空间图，再经卷积或全连接得到每个空间位置的权重，与原特征逐位置相乘，突出“哪里”重要。

**常见实现：** 通道维 MaxPool + AvgPool 得到两张 (1,H,W)，concat 后 7×7 卷积 + Sigmoid 得到空间权重图 (1,H,W)，再与输入逐元素乘。

**结构示意：**

```
输入 (C,H,W) ──┬──→ [Channel MaxPool] ──→ (1,H,W) ──┐
               └──→ [Channel AvgPool]  ──→ (1,H,W) ──┼── concat (2,H,W) ──→ [7×7 Conv] ──→ Sigmoid ──→ (1,H,W)
                                                      │                                                      ↓
输入 ─────────────────────────────────────────────────┴────────────────── 逐元素乘 ──────────────────────→ 输出
```

- 可与 SE 串联使用：先 SE（通道），再 SAM（空间），即 **CBAM** 的简化版。

---

## 小结

| 模块 | 关注维度 | 作用                     |
|------|----------|--------------------------|
| SE   | 通道     | 强调重要通道，抑制冗余   |
| SAM  | 空间     | 强调重要区域，抑制背景   |

实现见 `se_sam.py`。
