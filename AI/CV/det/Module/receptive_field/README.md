# 感受野增强模块

在固定分辨率特征图上，通过**多尺度池化或卷积**扩大有效感受野，使同一位置能融合更大范围的上下文，有利于大目标与场景理解。常用模块有 SPP、ASPP、RFB。

---

## 1. SPP（Spatial Pyramid Pooling）

**出处：** Spatial Pyramid Pooling in Deep Convolutional Networks (ECCV 2014)

**思想：** 对同一特征图做**多个不同尺寸的池化**（如 5×5、9×9、13×13），将各池化结果在通道维拼接，再经卷积融合。这样一次前向即可得到多尺度上下文，且对输入尺寸不敏感。

**结构示意：**

```
输入特征 ──┬──→ [MaxPool 5×5]  ──→ [1×1] ──┐
           ├──→ [MaxPool 9×9]  ──→ [1×1] ──┼── concat ──→ [1×1] ──→ 输出
           ├──→ [MaxPool 13×13] ─→ [1×1] ──┘
           └──→ [恒等/1×1] ────────────────┘
```

- 在 YOLOv3/v4 等中，SPP 常放在 Backbone 末端，扩大 C5 感受野后再送入 Neck。

---

## 2. ASPP（Atrous Spatial Pyramid Pooling）

**出处：** DeepLabv2/v3（空洞卷积 + 多尺度并行）

**思想：** 用**不同膨胀率的 3×3 空洞卷积**并行分支，再加**全局平均池化**分支，在通道维拼接后 1×1 融合。在不降低分辨率的前提下扩大感受野，且多尺度并行。

**结构示意：**

```
输入 ──┬──→ [3×3 conv rate=6]  ──┐
      ├──→ [3×3 conv rate=12] ──┼── concat ──→ [1×1] ──→ 输出
      ├──→ [3×3 conv rate=18] ──┤
      └──→ [GlobalAvgPool + 1×1] ┘
```

- **空洞率 (rate)**：卷积核采样间隔，rate=2 即 3×3 等价于 5×5 感受野，且参数量不变。

---

## 3. RFB（Receptive Field Block）

**出处：** Receptive Field Block Net for Accurate and Fast Object Detection (ECCV 2018)

**思想：** 类似 Inception 的**多分支**：不同大小的卷积核（1×1、3×3、5×5 等）与**不同膨胀率**组合，在通道维拼接后 1×1 融合，模拟多尺度感受野。

**结构示意：**

```
输入 ──┬──→ [1×1] ──────────────────┐
      ├──→ [1×1] → [3×3 rate=1] ────┼── concat ──→ [1×1] ──→ 输出
      ├──→ [1×1] → [3×3 rate=2] ────┤
      └──→ [1×1] → [3×3 rate=3] ────┘
```

- 常用于 SSD、RFB-Net 等，在检测头前增强单层特征的多尺度表达。

---

## 小结

| 模块 | 核心操作           | 典型用途           |
|------|--------------------|--------------------|
| SPP  | 多尺度 MaxPool     | YOLOv3/v4 Backbone 末端 |
| ASPP | 多膨胀率空洞卷积   | DeepLab、语义分割 / 检测 |
| RFB  | 多分支卷积+空洞    | RFB-Net、SSD 增强  |

实现见 `spp_aspp_rfb.py`。
