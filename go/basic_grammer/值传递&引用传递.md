## 值传递

函数中修改形参，不影响实参

## 引用传递

函数内部修改形参，影响实参

## Go只有值传递

go语言官方强调，所有的函数参数传递都是值传递，只传实参的副本。但是如果实参是指针，参数传递是指针的副本，依然能改变实参所指的数据对象，将会达到引用传递的效果。

### 指针传递

其中 **channel func map slice pointer**这些数据类型，传递时默认传递底层数据对象的内存地址，因此有引用传递的效果。

有内部指针的转换。

```go
func (p *pp) fmtPointer(value reflect.Value, verb rune) { 
 var u uintptr 
 switch value.Kind() { 
 	case reflect.Chan, reflect.Func, reflect.Map, reflect.Ptr, reflect.Slice, reflect.UnsafePointer: 
 	 	u = value.Pointer() 
 	default: 
  		p.badVerb(verb) 
  return 
 } 
```

#### map

```go
func ParaType() {
	m := make(map[string]string)
	m["key"] = "val"
	fmt.Printf("the map type:%v\n", reflect.TypeOf(m))
	fmt.Printf("the map content:%v\n", reflect.ValueOf(m))
	fmt.Printf("main:the value of m：%p\n", m)
	fmt.Printf("main: the addres of m：%p\n", &m)
	mapAfterFunc(m)

	fmt.Printf("%v", m)
}

func mapAfterFunc(m map[string]string) {
	fmt.Printf("hello: the value of m：%p\n", m)
	fmt.Printf("hello:the address of m：%p\n", &m)
	m["key"] = "new val"
}
```

注意m是一个地址，main和hello中的m并不是同一个，可以看出是值传递，但是因为值是指针，所以他们都会指向相同的地址0xc000076150，即map存数据的地址，因此直接修改m是能够修改原内容的。

**out**

```go
the map type:map[string]string
the map content:map[key:val]
main:  the value of m：0xc000076150
main:  the addres of m：0xc00000e028
hello: the value of m：0xc000076150
hello: the address of m：0xc00000e038
map[key:new val]
```

其他数据类型就不一一测试了

### 数据传递

基本数据类型无论在哪里都是值传递，都需要传递变量的地址，才能修改对象，但是数组和字符串在go中较为特殊，下面测试一下。

#### array

```go
func ParaType() {
	// array
	a := [3]int{1, 2, 3}
	fmt.Printf("the  array type:%v\n", reflect.TypeOf(a))
	fmt.Printf("the array content:%v\n", reflect.ValueOf(a))
	fmt.Printf("the value of a：%v\n", a)
	fmt.Printf("the address of a：%p\n", &a)
	arrayAfterFunc(a)
	fmt.Printf("%v\n", a)
}

func arrayAfterFunc(a [3]int) {
	a[0] = 4
}
```

**注意数组a它不是一个地址，它代表整个数组，需要修改数组的内容，需要传递指针才行**

**out**

```go
the  array type:[3]int
the array content:[1 2 3]
the value of a：[1 2 3]
the address of a：0xc000014330
[1 2 3]
```

#### string

string，本质是一个byte数组，因此效果应该和上面的数组一致

```go
func ParaType() {
	// string
	s := "abcde"
	fmt.Printf("the type of s:%v\n", reflect.TypeOf(s))
	fmt.Printf("the content of s:%v\n", reflect.ValueOf(s))
	fmt.Printf("the value of s：%s\n", s)
	fmt.Printf("the address of s：%p\n", &s)
	stringAfterFunc(s)
	fmt.Printf("%v\n", s)
}

func stringAfterFunc(s string) {
	for _, val := range s {
		val += 1
	}
}
```

注意1 string 不能用下标访问

注意2 s代表的任然是整个字符串，不是一个地址，因此直接传递s，依然是值的拷贝，在函数stringAfterFunc不会改变s

out

```go
the type of s:string
the content of s:abcde
the value of s：abcde
the address of s：0xc000116250
abcde
```
